# 🛍️ Customer Behavior Analysis

An end-to-end **Data Analytics project** focused on understanding customer purchasing behavior, spending patterns, product preferences, and demographic trends. The project uses **Python, SQL, and Power BI** to transform raw customer data into meaningful business insights and interactive visualizations.

---

## 📌 Overview

The objective of this project is to analyze customer shopping behavior and identify patterns that can help businesses understand their customers and make **data-driven decisions**.

The project follows a complete analytics workflow:

**Raw Dataset → Python → Data Cleaning & EDA → SQL Analysis → Power BI Dashboard → Business Insights → Report & Presentation**

---

## 📂 Dataset

The dataset contains customer shopping information such as:

* Customer ID
* Age & Gender
* Item Purchased
* Category
* Purchase Amount
* Location
* Size & Color
* Season
* Review Rating
* Subscription Status
* Shipping Type
* Discount Applied
* Promo Code Used
* Previous Purchases
* Payment Method
* Frequency of Purchases

## 🔄 Project Workflow

### 1. 📥 Data Loading

Loaded the raw dataset into Python using Pandas and inspected its structure, columns, data types, and basic statistics.

### 2. 🧹 Data Cleaning

Performed data preprocessing including:

* Handling missing values
* Checking duplicate records
* Correcting data types
* Creating useful categories/features
* Preparing the dataset for analysis

### 3. 🔍 Exploratory Data Analysis

Analyzed:

* Customer demographics
* Purchase patterns
* Product categories
* Spending behavior
* Customer ratings
* Discounts and subscriptions
* Payment methods
* Shipping preferences

### 4. 🗄️ SQL Analysis

Loaded the cleaned dataset into SQL and created queries to answer important business questions, such as:

* Which products generate the highest sales?
* What is the average purchase amount?
* Which customers spend more than average?
* How do discounts affect customer spending?
* Which categories receive the highest ratings?
* What are the most preferred payment methods?

### 5. 📊 Power BI Dashboard

Created an interactive dashboard to visualize key KPIs and customer trends.

**Dashboard includes:**

* Total Customers
* Total Sales
* Average Purchase Amount
* Average Rating
* Sales by Category
* Sales by Season
* Customer Demographics
* Payment & Shipping Analysis
* Subscription & Discount Analysis

## 📈 Results & Insights

The analysis helps identify:

* Customer purchasing patterns
* High-performing product categories
* Spending behavior across customer segments
* Impact of discounts and subscriptions
* Preferred payment and shipping methods
* Seasonal purchasing trends
* Opportunities for improving customer engagement and sales

These insights can help businesses make better decisions related to **marketing, customer segmentation, pricing, promotions, and product strategy**.

## ▶️ How to Run

### Step 1 — Clone the Repository

```bash
git clone <your-repository-url>
```

### Step 2 — Navigate to the Project

```bash
cd customer_behavior_analysis
```

### Step 3 — Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn
```

### Step 4 — Run the Python Analysis

Open the Jupyter Notebook or Python file and run the analysis.

### Step 5 — SQL Analysis

Import the cleaned dataset into your preferred SQL database:

**MySQL / PostgreSQL / SQL Server**

Run the provided SQL queries to reproduce the analysis.

### Step 6 — Power BI

Open the `.pbix` file in Power BI Desktop and refresh the data if required.
